Getting started

Edit the active .sam file, then use Run or Step. Assembly errors are shown directly in the editor and the current program counter can follow the corresponding source line.

FilesUse New/Open for tabs. Download saves the active tab to your device.
ShareShare copies a URL containing the active program and filename. Opening the link creates a new tab; the source stays in the URL fragment.
AutocompleteStart typing an instruction or press Ctrl/Cmd+Space. Labels in the current file are suggested too. You can disable autocomplete in Settings.
ISA referenceOpen Settings → ISA Reference to search every SaM instruction. Hover an opcode in the editor for quick documentation.
SettingsUse the gear for theme, font size, tab width, wrapping, and PC highlighting.
MobileOn a phone, switch between Editor and Simulator using the view buttons above the workspace.

Keyboard shortcuts

Ctrl/Cmd+Enter Run   F10 Step   Ctrl/Cmd+S Download   Ctrl/Cmd+Space Autocomplete

Your open tabs and editor settings are stored locally in this browser.
